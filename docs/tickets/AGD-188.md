# AGD-188 - Apply Lazy Loading to Appointment Lists and Tables

## Objective

Improve appointment table performance by loading records in pages instead of pulling the full appointment list into the client.

## Scope

- Keep the Admin Appointment page paginated across Pending, Approved, Completed, Cancelled, and All status filters.
- Apply date filters and search to the same paginated backend request.
- Avoid client-side full-list filtering for searches on appointment records.
- Keep visible loading feedback while searches or page changes are running.

## Changes

- Added `search` support to the admin master-list API.
- Applied master-list search before pagination so results stay accurate by page.
- Updated the Admin Appointment page to use `getAdminMasterListPage` for both normal browsing and search.
- Search now participates in the existing page cache key through the request filters.
