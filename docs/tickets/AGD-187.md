# AGD-187 - Clarify Flutter Device Launch Workflow

## Objective

Make the local Flutter launch workflow clearer when targeting an emulator or wireless Android device.

## Issue Addressed

- Running `flutter run` from the repository root fails because `pubspec.yaml` is inside `frontend/`.
- Running `flutter run emulator-5554` from `frontend/` fails because Flutter treats `emulator-5554` as a target file unless the `-d` device flag is used.

## Changes

- Documented the correct device command: `flutter run -d emulator-5554`.
- Updated the frontend helper script to accept `-d <device-id>` and `--device <device-id>`.
- Kept positional device id support for the existing `./scripts/run_phone.sh emulator-5554` workflow.
- Documented root-launched helper examples such as `frontend/scripts/run_phone.sh -d emulator-5554`.

## Verification

- `bash -n frontend/scripts/run_phone.sh`
