# AGD-189 - Apply Lazy Loading to Patient and Staff Account Tables

## Objective

Improve patient and staff account table performance by loading accounts in pages instead of pulling all records into the client.

## Scope

- Keep patient account records paginated in the Admin Patients view.
- Keep staff and intern account records paginated in the Admin Staff view.
- Apply search to the backend query before pagination.
- Keep loading feedback visible while search and page changes are running.

## Changes

- Added `search` support to the admin patient and staff listing APIs.
- Updated patient and staff services to include search terms in paginated requests and page cache keys.
- Removed client-side full-list search from the Admin Staff view.
- Updated Admin Patients search results to keep pagination controls available.

- `php artisan test --filter=AdminStaffControllerTest`
